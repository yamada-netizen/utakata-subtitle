「テーマはあるけど素材がない・見つからない」を解消する整理ルール

🚨 現状の問題

  • サロンで撮影していないもの（外部素材）の整理が煩雑
  • 「肌が弱い花嫁向けの素材どこ？」と探すのに時間がかかる
  • 「施術ごと」「お客様の感想」が混ざって管理されている
  • 過去に撮った良い素材を再活用できない

🔍 この設計の威力

「肌弱」で検索 → 関連素材が全部出る

Mac の Finder / Windows のエクスプローラ / Google Drive の検索で「肌弱」と入力するだけで、 施術動画もお客様の声も全部 ヒットします。

必須 ファイル名は 必ず日本語OKなツール で管理（Google Drive は日本語検索◎）

🚀 初期構築の手順

  1. Google Drive にメインフォルダ作成（10分）
    上記のフォルダ構造を一気に作る。サロンのGoogleアカウントで作るのが理想
  2. 過去素材を一度全部ぶち込む（30分）
    スマホやPCにある動画を「99_アーカイブ」に一旦集める。整理は後でOK
  3. 直近1ヶ月分だけ仕分け（60分）
    古いものは「99_アーカイブ」のままでOK。最近のものだけ整理する
  4. 命名規則を統一（30分）
    仕分けながらファイル名を上記ルールに変更
  5. 新規撮影分から命名ルール適用（運用開始）
    撮影後すぐにファイル名を付ける習慣をつける
  6. 月1で整理タイム（30分）
    月末に未整理ファイルを仕分け・削除

🛠 おすすめのクラウドストレージ

🥇 Google Drive（おすすめ）

無料15GB / 100GBで月250円 / 2TBで月1,300円

  • 日本語ファイル名・日本語検索◎
  • スマホ・PC・タブレットすべて同期
  • 共有が簡単（スタッフ間で共有可）
  • Edits や CapCut から直接アクセス可

🥈 iCloud Drive

5GB無料 / 50GBで月130円 / 200GBで月400円

  • iPhone ユーザーなら標準で同期されて楽
  • ただし複数人での共有はやや弱い

🥉 Dropbox

2GB無料 / 2TBで月1,500円

  • 大容量プランが安定
  • 動画素材の共有に強い

🏷 さらに上級: タグ運用（任意）

フォルダ構造だけだと 「2軸で探したい時」が苦手。 例えば「肌弱 × ブライダル × 完成動画」のような複合検索。

この場合、Notion か Airtable で素材データベース を作ると、複数タグで絞り込み可能になります。

  • Notion: 無料で十分。ファイル名・タグ・サムネ・メモを管理
  • Airtable: スプレッドシート + データベース。視覚的に管理

※ まずはフォルダ構造だけで運用してみて、不便を感じたら導入を検討
