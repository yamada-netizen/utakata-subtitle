うたかた 業務フロー詳細ヒアリングシート

対象: 代表 / 個人エステサロン 形式: 訪問ヒアリング用 / 所要 約60〜90分

1. このシートについて

今回は、今後の方向性や理念をお聞きするのではなく、普段の業務の流れを一つずつ確認し、 時間を短縮できる部分や、仕組みにできる部分がないかを一緒に整理するためのヒアリングです。
「できていないこと探し」ではなく、仕組みにすることで丁寧さを保ちやすくする視点で進めます。

2. ヒアリングの進め方

抽象的に「普段どうしていますか？」と聞くのではなく、最近来店された具体的なお客様お1人を思い浮かべていただき、 その方が予約する前から、来店、施術、会計、次回案内、記録、フォローまでを時系列で確認していきます。

思い浮かべるお客様 最近来店された方の中で、新規 or 直近のリピーターから1名を選んでください（記名不要、頭の中だけでOK）
確認の順序 予約前 → 問い合わせ → 予約確定 → 来店前 → 来店 → 施術 → 会計 → 次回案内 → 記録 → フォロー → その後の管理 まで時系列で
確認しないこと 理念・将来像・お悩み相談（別の機会に伺います）

4. 工程別ヒアリング項目

01認知・問い合わせ前

確認したいことお客様がうたかたをどこで知り、何を見てから問い合わせに至るか。予約導線の現状。
具体的な質問
  1. 直近で来てくださった新規のお客様は、どこでうたかたを知ったとおっしゃっていましたか？
  2. Instagramのプロフィール・ハイライト・固定投稿で、「来店前にこれは見ておいてほしい」と思っている情報は何でしょうか？
  3. 料金表や予約フォームは、今どの導線から辿れるようになっていますか？
  4. 「問い合わせ前にここを見てから来た」と分かるお客様はいらっしゃいますか？
確認したい資料・画面Instagramプロフィール / ハイライト / 固定投稿 / 予約フォーム or 予約導線リンク
改善余地のポイント予約導線がInstagram内で完結しているか / 料金や所要時間の表示が古くなっていないか / 初回FAQが分散していないか
想定される提案例「来店前にご覧いただきたいこと」をまとめた固定投稿 / プロフィール下のリンク集（リットリンク等）整理 / 初回向けハイライト再構成

02問い合わせ・初回相談

具体的な質問

  3. 予約が確定するまで、平均何往復くらいやりとりが発生しますか？
  4. 同じ説明を毎回手で打って案内している、と感じる場面はありますか？
確認したい資料・画面直近のDM / LINE のやりとり履歴（記名部分は飛ばしてOK）
改善余地のポイント初回対応で毎回同じ説明を手入力していないか / 返信に時間がかかっていないか / 質問の取りこぼしがないか
想定される提案例初回問い合わせ返信テンプレ（DM / LINE 別） / よくある質問の定型文セット / 初回案内PDF

8. 面談時の注意点（支援者向け）

尋問にしない「なぜそうしていないのですか」ではなく「いまはどうされていますか」と聞く
否定しないこだわりや丁寧さを「効率化対象」として扱わない
探しに行かない「できていないこと探し」にしない。事実だけ聞く
効率化を目的にしない仕組み化は丁寧さを保つための手段、という伝え方をする
世界観を壊さないうたかたらしい静けさ・誠実さを損なう提案はしない
押し売りに転化させない売上機会の話は「必要な案内が届いていない可能性」として扱う
ペースを合わせる1工程ごとに区切り、急かさない。話が広がる工程はそこで深掘る
